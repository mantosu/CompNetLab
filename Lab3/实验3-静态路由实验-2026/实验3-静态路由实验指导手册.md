本指导手册内容来自：《计算机网络实验教程》（第 2 版），王盛邦编著，清华大学出版
社，ISBN：9787302461234，2017 年 5 月

【实验目的】
掌握通过静态路由方式实现网络的连通性。

【实验内容】
完成本实验及实验思考。
在路由器 R1 和 R2 上配置静态路由，使 PC1 和 PC2 在跨路由器的情况下能
互连互通。配置之前，应该测试  2  台计算机的连通性，以便与配置后的连通
性作对比。

【实验步骤】
注意，实验室每台 PC 都有 2 块网卡：1 块网卡（IP 已被配置为 172.16.X.1-3，X 为小组号）用于
连接校园网、以访问互联网，以及配置实验室所在小组的路由器和交换机；1 块网卡用于在路由
器和交换机配置好后，参与课程实验，其 IP 需手动配置，在本实验中配置为 192.168.X.X。若想
令两块网卡在实验中同时使用，需手动配置 PC 的网络路由。若不想手动配置路由，可以在静态
路由实验时禁用 PC 上 172.16.X.1-3 的网卡（不要拔掉 PC 的网线）。

步骤四：配置静态路由

●  在 R1 上配置去往 PC2 所在网段的静态路由
[R1] ip route-static 192.168.3.0 24 192.168.2.2

●  在 R2 上配置去往 PC1 所在网段的静态路由（回程路由）

[R2] ip route-static 192.168.1.0 24 192.168.2.1

步骤五：验证测试

1.  查看路由表

在 R1 和 R2 上分别执行 display ip routing-table 命令，检查静态路由条目是否已成功加
载。
○  R1 预期输出（部分）:

Destination/Mask    Proto   Pre  Cost      Flags NextHop         Interface
192.168.1.0/24      Direct  0    0           D   192.168.1.1     Ethernet0/0/1
192.168.2.0/24      Direct  0    0           D   192.168.2.1     Ethernet0/0/2
192.168.3.0/24      Static  60   0          RD   192.168.2.2     Ethernet0/0/2

2.  测试端到端连通性

○  在 PC1 的命令行界面执行 ping 192.168.3.22。

C:\>ping 192.168.3.22

Pinging 192.168.3.22 with 32 bytes of data:
Reply from 192.168.3.22: bytes=32 time<1ms TTL=126
Reply from 192.168.3.22: bytes=32 time<1ms TTL=126

出现以上回复，证明 PC1 与 PC2 已成功连通。
