## 心得体会

排错要从近到远。这次实验里 PC1 ping R1 互联口一直超时，`tracert` 才发现第一跳走的是校园网网关 `172.16.0.1`——双网卡各有一个默认网关，Windows 把实验流量从校园网网卡发出去了。顺着"接口状态 → 路由表 → 逐段 ping → 主机侧"的顺序查，比一上来乱改配置有效得多。同样，手册上的接口名和实际设备不一致，也是先 `display ip interface brief` 确认之后才少走了弯路。

记录是实验的一部分。每完成一步就立即截图，并记下命令、输出和当时的现象。这一次实验中我主要负责 PC1、R1 的配置和写实验报告。写实验报告很重要的一个步骤就是收集数据和截图、及时如实记录实验过程和结果，我意识到做实验重要的不仅仅是操作本身，记录也很重要。操作做完就过去了，只有当时记下的东西，才能支撑报告里的分析和结论。
